# 2D Transformations in graphics.h

C++ programs for the three basic 2D transformations, drawn with `graphics.h`.

| File | Transformation |
|---|---|
| `Translation.cpp` | Translate a shape by (tx, ty) |
| `Rotation.cpp` | Rotate a shape by an angle |
| `Scaling.cpp` | Scale a shape by (sx, sy) |

## Run
Needs a `graphics.h` setup such as WinBGIm with Code::Blocks or Dev-C++. Open a file, build, and run.
